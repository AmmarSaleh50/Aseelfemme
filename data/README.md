# Import Data

This folder contains JSON files ready to import into the admin panel.

## How to Import

### Categories
1. Go to `/admin/categories`
2. For each category in `categories.json`, click "Add Category" and paste the values

### Ingredients
1. Go to `/admin/ingredients`
2. Click "New Ingredient"
3. Click the "Import" button
4. Select `ingredients.json`

## Common Product Tags
All products should include these tags:
- SLS free
- Hand made
- 100% natural extracts

Add these when creating products in the "Tags" field (comma-separated).
